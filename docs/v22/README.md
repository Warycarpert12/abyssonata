# v22: проверка

Снимки «было (main) / стало (v22)» — `*.jpg` в этой папке. Скрипты проверки — `qa/` (в репозитории они только здесь:
корневая папка `qa/` по `.gitignore` остаётся на ПК). Скриптам нужен Playwright с Chromium и собранный сайт
(`python build_site.py`, затем любой статический сервер над `_site/`); адрес страницы — с `?qa`.

| Скрипт | Что проверяет |
|---|---|
| `move_check_split.mjs <web эталона> <web ветки>` | баланс мира: 8 миров × 40 игровых минут, события, численность, отпечаток |
| `mix_check.mjs <audio.js эталона> <audio.js ветки>` | нормализация и разбор записей — побитово как в main |
| `perf_profile.mjs <адрес> [сек] [замедление CPU]` | профиль кадров (CDP): долгие кадры, сборка шейдеров, распаковка звука, GC |
| `fish_check.mjs`, `hover_check.mjs`, `quality_check.mjs` | рыбы не в острове, подпись при наведении, качество картинки |
| `desktop_check.mjs`, `mobile_check.mjs`, `ios_check.mjs` | ПК, телефон (касания), эмуляция iPhone и «старого Safari» |
| `shots.mjs` | снимки для сравнения |
