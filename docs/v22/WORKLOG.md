# Abyssonata (бывш. Ocean Murmur): что сделано в v21 → v22

Живой океан в браузере: остров, риф, звери-агенты; погода, сутки, звук и картинка идут от одного мира.
Сайт собирается `build_site.py` → `_site/`, публикуется GitHub Pages (`.github/workflows/pages.yml`), APK — Capacitor
(`.github/workflows/apk.yml`, по тегу `v*`). Подробные цифры и скрипты проверки — [README.md](README.md) в этой папке.

## v22, часть 1 — исправления и новое

1. **Фризы раз в ~10 с** — шейдеры собирались посреди игры (каждый новый вид зверя и эффект), плюс ~230 записей звука
   распаковывались разом после входа. Теперь шейдеры собираются заранее на экране входа, звук распаковывается по одной записи.
2. **iPhone** — звук создаётся прямо в нажатии; работает при беззвучном переключателе (`audioSession` + тихий `<audio>`);
   будится касанием после блокировки; старый Safari и браузеры без модулей — понятное сообщение.
3. **GitHub Pages** — нет запроса `/api/join` (красная ошибка в консоли).
4. **Рыбы не заходят в остров** — было 0.39% рифовых и 31% стаек у острова, стало 0 из 2.1 млн проверок.
5. **Подпись при наведении** — стабильная (зона по размеру зверя на экране).
6. **Телефон** — «Обитатели» и журнал листаются пальцем, выбор — только коротким тапом.
7. **Качество: Авто / Высокое / Низкое**, Авто не опускается ниже 1 точки на пиксель экрана («мыло» на Honor 30).
8. **Пауза** (кнопка и пробел). 9. **Журнал** — спокойнее, «×N», клик ведёт камеру. 10. **Камера на звере** — вращение
   и приближение, Esc отпускает. 11. **Кнопка «Линза»**. 12. **Подсказки к «Состоянию»**. 13. **Кнопки времени суток**.
14. **Экран входа** — стеклянная карточка, за ней размытый живой мир, при входе карточка рассыпается.

## v22, часть 2 — экран входа, контрольный прогон, новое имя

- Пока открыта карточка, интерфейс мира скрыт и не ловит нажатия; после входа проявляется за ~0.9 с.
- Найдено и исправлено (по коммиту на каждое): нижний ряд кнопок налезал на журнал; вход стал дольше (4.4 → 1.4–1.6 с);
  пауза + время суток не меняли небо; рельеф считается в 1.6–1.8 раза быстрее (тот же результат до бита); щелчок при
  паузе (теперь плавное затухание за 60 мс); кости и крылья эффектов не освобождались в видеопамяти; карточка исчезала
  разом на слабом устройстве (теперь рассыпается, не дольше 4 с).
- По находкам независимого проверяющего: «слабое устройство» распознавалось на 2 с раньше, чем в main; в окне ПК 800×600
  кнопки вставали столбиком (теперь компактная раскладка); чистка неиспользуемого.
- **Переименование Ocean Murmur → Abyssonata**: вкладка, экран входа, manifest, credits, README, THIRD_PARTY, LICENSE,
  комментарии, имя APK (`Abyssonata.apk`). Идентификатор APK `io.github.warycarpert12.oceanmurmur` оставлен. Ключи
  настроек `om.*` → `abyssonata.*` с переносом сохранённого. Слово «murmur» осталось только в строке README
  «Вдохновлено murmur.living.» (решено оставить) и в идентификаторе APK.

## Перед слиянием (по решению автора)

- iPhone/iPad: записи хранятся в 32 кГц, звук играет в родной частоте устройства. Память записей: после входа 147 → 94 МБ,
  все категории 477 → 314 МБ (в v21 Safari закрывал вкладку около 560 МБ). ПК — как в main.
- «Поверните телефон» — только на сенсорных экранах; окно ПК уже 600 px — «Растяните окно шире».
- LICENSE — стандартный текст MIT без добавок (GitHub покажет MIT).
- Оставлено как есть: строка про murmur.living, звук в свёрнутой вкладке, снимки «было» в docs, служебные пометки
  `__om`/`om-site`. Скрипта, который собирает THIRD_PARTY.md и credits.html, в репозитории нет.

## Осталось сделать

1. **Переименовать репозиторий** (автор): Settings → General → Repository name → `abyssonata`.
2. После «переименовал»: перезапустить сборку сайта; создать репозиторий `ocean-murmur` с одним `index.html`-перенаправлением
   на `https://warycarpert12.github.io/abyssonata/`; автору — включить для него Pages (Settings → Pages → Deploy from a
   branch → `main` / `(root)`); проверить оба адреса.
3. Локальная копия на ПК: `git remote set-url origin https://github.com/Warycarpert12/abyssonata.git`.
4. Метка состояния main перед v22 (из облака отправить не удалось — 403):
   `git fetch origin && git tag -a before-v22 5da63645aab078dd42e13d9b2d45610b191f9f8b -m "main перед v22" && git push origin before-v22`
5. Новый выпуск APK (тег, например `v22`) — появится `Abyssonata.apk`; старая прямая ссылка на `OceanMurmur.apk`
   перестанет работать.
6. Проверить на настоящем iPhone 15 минут (память) и пройти 5-минутный список на ПК и телефоне.

- Симуляция, баланс и микс звука совпадают с main — проверка скриптом на 8 мирах после каждого коммита.
- Один коммит — одна правка; спорное не трогать, выносить в отчёт.
- В main не пушить; сливать, переименовывать и удалять — только после слова автора («сливай», «переименовал»).
- Отчёты — по-русски, простыми словами.
